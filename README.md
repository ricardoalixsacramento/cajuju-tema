# Cajuju — tema Shopify

Tema da loja Cajuju (roupa de bebé feita em Portugal). Ligado à Shopify pela integração GitHub: cada commit no ramo `main` atualiza o tema ligado na loja.

- Regras partilhadas entre AI: ver `AGENTS.md` na pasta `Desktop\Cajuju\AI`.
- Não alterar `config/settings_data.json` à mão sem necessidade: a Shopify escreve aí as alterações feitas no editor do tema.
